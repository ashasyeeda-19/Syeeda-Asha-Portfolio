# Syeeda Asha Portfolio

## 📌 Project Overview
This is my personal portfolio website developed using HTML, CSS, and JavaScript. The website showcases my profile, education, projects, achievements, and provides a contact form connected with EmailJS.

## ✨ Features
- Responsive Portfolio Website
- Home Section
- About Me
- Education
- Projects
- Achievements
- Contact Form (EmailJS Integration)
- CV Download
- Social Media Links

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- EmailJS
-Font Awesome

## 📂 Project Structure

```
Syeeda-Asha-Portfolio/
│── index.html
│── style.css
│── script.js
│── images/
│── cv/
│── README.md
```

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ashasyeeda-19/Syeeda-Asha-Portfolio.git
```

### 2. Open the project folder

```bash
cd Syeeda-Asha-Portfolio
```

### 3. Run the project

Open **index.html** in your web browser.
